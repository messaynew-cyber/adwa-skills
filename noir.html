The loop

01
Build something reusable

Tobia writes a tool with create_tool. If it will be useful again, it gets a version and a changelog.

02
Publish

skill_store action=publish uploads the manifest and regenerates this index. Secrets are refused before anything leaves the device.

03
Install anywhere

skill_store action=install name="…" fetches it, checks the version, verifies the hash, and registers it live.
