New capabilities, no rebuild.

Tobia builds a tool, publishes it here, and installs it on any device in one line. Every manifest is versioned and hashed — and anything carrying a credential is refused before it leaves the device.

The loop

01 · BUILD
Forge a tool

create_tool writes it at runtime. If it earns its keep, it gets a version and a changelog.

02 · PUBLISH
Ship it

skill_store action=publish uploads the manifest and regenerates this page. Secrets are refused.

03 · INSTALL
Use it anywhere

action=install name="…" checks the version, verifies the hash, registers it live.
