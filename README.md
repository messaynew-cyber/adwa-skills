# adwa-skills

Tobia skill registry. Served via GitHub Pages.

Store index: https://messaynew-cyber.github.io/adwa-skills/index.json

Every `.skill` is a JSON manifest (schema 2): name, description, parameters,
code, version, requires_keys, sha256, changelog.

Publishing is done by Tobia (`skill_store action=publish`) or by committing here.
